## Selected Research & Projects

### GNN-Transformer: Graph-Augmented Tabular Learning

**Undergraduate senior project · NetAI Lab, NCKU · Advisor: Prof. Cheng-Te Li**

Explored how graph neural networks can improve ExcelFormer's tabular prediction by capturing relationships between data rows.

- Designed and implemented **Multi-thread Adaptive Mutual kNN** graph construction to capture inter-row relationships and accelerate graph generation.
- Integrated **GraphSAINT-RW** subgraph sampling to reduce memory usage compared with full-graph GNN training.
- Evaluated **three GNN-Transformer integration architectures**. The parallel design achieved better predictive performance across multiple datasets and completed training faster than ExcelFormer.

This research was supported by the **NSTC College Student Research Project** (July 2025–February 2026) and was a **finalist in the NCKU CSIE 2026 Senior Project Exhibition**.

### Anti-Scam Agent

**Collaborative agentic AI project**

Co-developed a two-agent system for assessing website risk without relying on blacklists:

- A **Browsing Agent** interacts with websites using synthetic inputs.
- An **Analysis Agent** assesses page content and interaction results to help users identify potentially malicious websites.
